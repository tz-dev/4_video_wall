Menu

Enter toggles menu. H toggles help. Space or P toggles play/pause all. M toggles mute all. 1-4 mute/unmute single video. Shift + 1-4 pause/resume single video. Ctrl + 1-4 toggles solo view. Close menu to drag videos.
Ready.

Help

Enter
Toggle menu
H
Toggle help screen
Space / P
Pause/resume all videos
M
Mute/unmute all videos
1-4
Mute/unmute video 1-4
Shift + 1-4
Pause/resume video 1-4
Ctrl + 1-4
Toggle solo view for video 1-4
L
Switch viewport layout
Esc
Exit solo view
Drag (menu closed)
Pan video within its cell
Scroll (menu closed)
Zoom video within its cell (100–300%)
Double-click (menu closed)
Reset pan & zoom to default
Mouse move
Show quick action bar when menu is hidden

Load a config to start. Saving config stores config name, layout mode, title, source mode, URL, loop points, volume, mute state, pan position, and zoom level for all videos in one JSON file. Browser-selected local files cannot be restored automatically after reload for security reasons, so those entries are marked and must be re-selected.
